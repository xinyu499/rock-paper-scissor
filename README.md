#Rock-Paper-Scissors Game

A simple rock-paper-scissor game using HTML, CSS, and Javascript to make a interactive game of user against computer the game will go on for 5 rounds.

## Features
-Interactive user interface.
-Computer randomly selects a choice of rock, paper, or scissor.
-Display the result of each round(e.g. You win! rock beats scissors).
-Display the result at the end of the game (e.g.: You win! Your Score: 3, Computer Score: 2).
-Styled with CSS for a clean and simple layout.
